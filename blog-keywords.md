# Blog Keywords — Machine Decides Journal

Keyword pool for the weekly Journal post. Same pattern as `themes.md`: pick from
`## Unused`, move to `## Used`, never reuse.

## Rules

1. Pick ONE keyword at a RANDOM position from `## Unused` — prefer buying/collector intent.
2. Move it to `## Used` immediately (date + NW query id + post URL). Never reuse — cannibalisation.
3. Run the full dual-draft NEURONwriter process (machine-decides skill `references/neuronwriter-seo-workflow.md`). `new-query` is pre-approved (1 per post).
4. Featured product follows the rotation rule: prefer a product NOT featured in the last 3 posts.
5. The `feature:` suggestion is a starting point — check recent posts first.
6. If a keyword's SERP turns out to be tool-intent/generator-intent garbage, mark it `REJECTED (intent)` in Used and pick another. Scoring/briefs are free — check intent BEFORE `new-query` where possible.
7. When Unused drops below 10, recycle Used entries older than 6 months back into Unused.
